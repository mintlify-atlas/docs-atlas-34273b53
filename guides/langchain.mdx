Faramesh integrates seamlessly with LangChain's `@tool` decorator. The `govern()` wrapper preserves all LangChain metadata including tool name, description, and `args_schema`.

## Installation

```bash
pip install faramesh langchain
```

## Quick Start

```python
from langchain.tools import tool
from faramesh import govern

@tool
def stripe_refund(amount: float, currency: str) -> str:
    """Refund a charge via Stripe."""
    # Your Stripe API call here
    return f"Refunded {amount} {currency}"

# Wrap with Faramesh governance
governed_refund = govern(
    stripe_refund,
    policy='payment.yaml',
    agent_id='payment-bot'
)

# LangChain metadata is fully preserved
print(governed_refund.name)         # "stripe_refund"
print(governed_refund.description)  # "Refund a charge via Stripe."
print(governed_refund.args_schema)  # Pydantic model generated by LangChain
```

## How It Works

The `govern()` decorator detects and preserves LangChain-specific attributes:

```python {10-14}
from faramesh import govern

@functools.wraps(fn)
def wrapper(*args, **kwargs):
    # ... governance logic ...
    return fn(*args, **kwargs)

# Preserve LangChain @tool metadata
if hasattr(fn, 'name'):
    wrapper.name = fn.name
if hasattr(fn, 'description'):
    wrapper.description = fn.description
if hasattr(fn, 'args_schema'):
    wrapper.args_schema = fn.args_schema
```

This ensures that LangChain agents and chains see the governed tool as if it were the original.

## Complete Example

```python
from langchain.tools import tool
from langchain.agents import initialize_agent, AgentType
from langchain.llms import OpenAI
from faramesh import govern, DenyError, DeferredError

# Define LangChain tools
@tool
def get_exchange_rate(from_currency: str, to_currency: str) -> float:
    """Get the exchange rate between two currencies."""
    # API call here
    return 1.12

@tool
def stripe_refund(amount: float, currency: str) -> str:
    """Refund a charge via Stripe."""
    # Stripe API call here
    return f"Refunded {amount} {currency}"

@tool
def send_email(to: str, subject: str, body: str) -> str:
    """Send an email to a customer."""
    # Email API call here
    return f"Sent email to {to}"

# Wrap all tools with governance
tools = [
    govern(get_exchange_rate, policy='payment.yaml', agent_id='payment-bot'),
    govern(stripe_refund, policy='payment.yaml', agent_id='payment-bot'),
    govern(send_email, policy='payment.yaml', agent_id='payment-bot'),
]

# Create LangChain agent
llm = OpenAI(temperature=0)
agent = initialize_agent(
    tools,
    llm,
    agent=AgentType.ZERO_SHOT_REACT_DESCRIPTION,
    verbose=True
)

# Run the agent — all tool calls go through Faramesh governance
try:
    result = agent.run("Refund $100 to customer cust_123")
    print(result)
except DenyError as e:
    print(f"Tool call denied: {e.reason}")
except DeferredError as e:
    print(f"Tool call requires approval: {e.defer_token}")
```

## Policy Example for LangChain Tools

```yaml payment.yaml
faramesh-version: '1.0'
agent-id: payment-bot
default_effect: permit

vars:
  max_refund: 500
  max_email_recipients: 10

rules:
  # Require approval for high-value refunds
  - id: defer-high-value-refund
    match:
      tool: stripe_refund
      when: 'args["amount"] > vars["max_refund"]'
    effect: defer
    reason: refund exceeds $500 threshold — requires finance approval
    reason_code: HIGH_VALUE_REFUND

  # Deny mass email
  - id: deny-mass-email
    match:
      tool: send_email
      when: 'len(args["to"].split(",")) > vars["max_email_recipients"]'
    effect: deny
    reason: mass email to >10 recipients requires manual review
    reason_code: MASS_EMAIL_LIMIT

  # Allow all other tools
  - id: permit-safe-tools
    match:
      tool: get_exchange_rate
    effect: permit
```

## Metadata Preservation

Faramesh preserves all LangChain tool attributes:

| Attribute | Description | Preserved |
|-----------|-------------|----------|
| `name` | Tool name | ✓ |
| `description` | Tool description (used by LLM) | ✓ |
| `args_schema` | Pydantic model for arguments | ✓ |
| `return_direct` | Return output directly to user | ✓ |
| `verbose` | Enable verbose logging | ✓ |
| `__wrapped__` | Reference to original function | ✓ |

```python
from langchain.tools import tool
from faramesh import govern

@tool(return_direct=True)
def search_database(query: str) -> str:
    """Search the customer database."""
    return "Results..."

governed_search = govern(search_database, policy='policy.yaml')

# All attributes preserved
assert governed_search.name == "search_database"
assert governed_search.description == "Search the customer database."
assert governed_search.return_direct == True
assert governed_search.__wrapped__ == search_database
```

## Error Handling with LangChain

LangChain agents can handle governance errors gracefully:

```python
from langchain.agents import Tool
from faramesh import govern, DenyError, DeferredError

def safe_stripe_refund(amount: float, currency: str) -> str:
    """Refund a charge via Stripe (governed)."""
    try:
        return governed_refund(amount=amount, currency=currency)
    except DenyError as e:
        return f"Error: Refund denied by policy. {e.reason}"
    except DeferredError as e:
        return f"Refund requires approval. Token: {e.defer_token}"

governed_refund = govern(stripe_refund, policy='payment.yaml')

# Wrap in LangChain Tool with error handling
refund_tool = Tool(
    name="stripe_refund",
    func=safe_stripe_refund,
    description="Refund a Stripe charge. May require approval for high amounts."
)
```

## Using with LangGraph

```python
from langgraph.prebuilt import create_react_agent
from langchain_openai import ChatOpenAI
from langchain.tools import tool
from faramesh import govern

@tool
def stripe_refund(amount: float, currency: str) -> str:
    """Refund a charge via Stripe."""
    return f"Refunded {amount} {currency}"

# Govern the tool
governed_refund = govern(
    stripe_refund,
    policy='payment.yaml',
    agent_id='payment-bot'
)

# Create LangGraph agent
model = ChatOpenAI()
agent = create_react_agent(model, [governed_refund])

# Run the agent
inputs = {"messages": [("user", "Refund $100 USD to customer")]}
for chunk in agent.stream(inputs):
    print(chunk)
```

## Using with Custom BaseTool

```python
from langchain.tools import BaseTool
from pydantic import BaseModel, Field
from faramesh import govern

class RefundInput(BaseModel):
    amount: float = Field(description="Refund amount in dollars")
    currency: str = Field(description="Currency code (e.g., 'usd')")

class StripeRefundTool(BaseTool):
    name = "stripe_refund"
    description = "Refund a Stripe charge"
    args_schema = RefundInput

    def _run(self, amount: float, currency: str) -> str:
        # This is the actual implementation
        return f"Refunded {amount} {currency}"

# Govern the _run method
base_tool = StripeRefundTool()
base_tool._run = govern(
    base_tool._run,
    policy='payment.yaml',
    agent_id='payment-bot',
    tool_id='stripe_refund'
)
```

## Advanced: Tool-Specific Policies

Use different policies for different tool categories:

```python
from faramesh import govern

# Financial tools — strict policy
financial_tools = [
    govern(stripe_refund, policy='financial.yaml', agent_id='payment-bot'),
    govern(create_invoice, policy='financial.yaml', agent_id='payment-bot'),
]

# Communication tools — permissive policy
comm_tools = [
    govern(send_email, policy='communication.yaml', agent_id='payment-bot'),
    govern(send_sms, policy='communication.yaml', agent_id='payment-bot'),
]

all_tools = financial_tools + comm_tools
```

## Testing Governed Tools

```python
import pytest
from faramesh import govern, DenyError

@tool
def stripe_refund(amount: float, currency: str) -> str:
    return f"Refunded {amount} {currency}"

governed_refund = govern(stripe_refund, policy='test-policy.yaml')

def test_refund_under_threshold():
    # Should PERMIT
    result = governed_refund(amount=100, currency='usd')
    assert "Refunded 100 usd" in result

def test_refund_over_threshold():
    # Should DENY or DEFER based on policy
    with pytest.raises(DenyError) as exc_info:
        governed_refund(amount=10000, currency='usd')
    assert exc_info.value.reason_code == "HIGH_VALUE_REFUND"
```

## Best Practices

<Steps>

<Step title="Govern at tool definition">
Wrap tools immediately after defining them:

```python
@tool
def my_tool(arg: str) -> str:
    """Tool description."""
    return arg

my_tool = govern(my_tool, policy='policy.yaml', agent_id='agent-id')
```
</Step>

<Step title="Use descriptive tool_id">
Override the tool ID for clearer policy rules:

```python
governed_refund = govern(
    stripe_refund,
    tool_id='stripe/refund',  # Matches policy rule: tool: stripe/refund
    policy='payment.yaml'
)
```
</Step>

<Step title="Handle errors in tool implementation">
Rather than letting errors propagate to the agent, handle them in the tool:

```python
@tool
def safe_tool(arg: str) -> str:
    try:
        return governed_impl(arg)
    except DenyError as e:
        return f"Action denied: {e.reason}"
```
</Step>

<Step title="Test policies before deployment">
Validate your policy file:

```bash
faramesh policy validate payment.yaml
faramesh policy test payment.yaml --tool stripe_refund --args '{"amount":10000}'
```
</Step>

</Steps>

## Troubleshooting

### LangChain doesn't see tool metadata

**Problem:** Agent can't find the tool or sees wrong description.

**Solution:** Ensure you're passing the governed tool to LangChain, not the original:

```python
# ✓ Correct
tools = [govern(my_tool, policy='policy.yaml')]

# ✗ Wrong
my_tool = govern(my_tool, policy='policy.yaml')
tools = [my_tool.__wrapped__]  # Don't unwrap
```

### Tool arguments not matching policy

**Problem:** Policy rule doesn't match the tool call.

**Solution:** Check that the `tool_id` in `govern()` matches the `tool:` in your policy:

```python
# Code
governed_tool = govern(my_tool, tool_id='stripe/refund')

# Policy
rules:
  - match:
      tool: stripe/refund  # Must match
```
