## Overview

The `faramesh demo` command runs a synthetic agent against a pre-loaded demo policy to showcase governance decisions in real time. This is the fastest way to see Faramesh in action — zero config, zero infrastructure, results in under 3 seconds.

```bash
faramesh demo
```

## What It Does

`faramesh demo` executes 5 synthetic tool calls against an embedded demo policy to demonstrate the three core governance effects:

- **PERMIT** — Tool call allowed
- **DENY** — Tool call blocked by policy or scanner
- **DEFER** — Tool call requires human approval

The demo runs entirely in-memory with no disk, socket, or infrastructure requirements.

## Technical Details

The demo command:
- Loads the embedded demo policy from `internal/embedded/demo_policy.yaml`
- Compiles the policy using the expr-lang engine
- Creates an in-memory pipeline with:
  - Policy engine
  - Null WAL (no disk writes)
  - In-memory session manager
  - DEFER workflow (no actual approvals)
- Evaluates 5 synthetic `CanonicalActionRequest` records
- Prints color-coded results with decision latency

<Note>
  The demo runs entirely in-memory. No data is written to disk, and no daemon is started.
</Note>
