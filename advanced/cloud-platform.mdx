### Community (OSS)

Run Faramesh entirely **offline** with no cloud dependencies:

```bash
faramesh serve --policy policy.yaml
# No auth required, no telemetry, 100% local
```

**Includes:**
- Policy engine (YAML + expr-lang)
- DPR chain (SQLite)
- All 6 adapters (SDK, daemon, sidecar, serverless, MCP, eBPF)
- Session state + budgets
- Multi-agent governance
- DEFER workflow
- Pre/post-condition scanners
- Credential routing
- Compensation engine

### Pro (Free Cloud Account)

Authenticate to unlock cloud-backed features:

```bash
faramesh auth login
# Opens browser, completes OAuth flow, stores token locally
```

**Includes everything in Community, plus:**
- **Cloud sync**: DPR chain replicated to cloud for backup
- **Rolling window budgets**: Time-based budget resets (hourly, daily, weekly)
- **Cloud registry**: Publish and consume policy packs
- **Cloud attestation**: Cryptographic proof of policy enforcement

### Team

**Includes everything in Pro, plus:**
- **Anomaly detection**: ML-based detection of unusual agent behavior
- **Cost forecasting**: Predict monthly spend based on usage trends
- **Private policy packs**: Org-private pack registry
- **Cross-org swarm**: Governance for agents spanning multiple orgs
- **Shared approval workflows**: Team-based DEFER approvals

### Enterprise

**Includes everything in Team, plus:**
- **Fleet management**: Centralized policy deployment across 1000+ agents

## Authentication

### Login to Faramesh Cloud

```bash
faramesh auth login
```

**Flow:**
1. Opens browser to `https://cloud.faramesh.dev/auth`
2. Complete OAuth (GitHub, Google, or email)
3. Token stored in `~/.faramesh/credentials.json`
4. Daemon auto-detects token on startup

**Manual token (CI/CD):**

```bash
export FARAMESH_CLOUD_TOKEN=fmsh_xxxxxxxxxxxxxxxxxxxxx
faramesh serve --policy policy.yaml
```

### Logout

```bash
faramesh auth logout
# Revokes token and deletes local credentials
```

### Check Auth Status

```bash
faramesh auth whoami
```

**Output:**
```
Logged in as: alice@example.com
Organization: Acme Corp
Plan: Team
Token expires: 2026-04-01 (30 days)
```

## Fleet Management

**Enterprise feature**: Centralized governance for large agent deployments.

### Deploy Policy Fleet-Wide

```bash
# Push policy to all agents in the fleet
faramesh fleet deploy policy.yaml --tag production
```

**Policy propagates to all registered agents within 30 seconds.**

### Register Agent to Fleet

```bash
# On each agent machine
faramesh agent register \
  --fleet production \
  --tags region=us-east,env=prod
```

### Fleet Status

```bash
faramesh fleet status
```

**Output:**
```
Fleet: production
Total agents: 1,247
Online: 1,235
Offline: 12

Policy version: 3a2f8b9c (deployed 2h ago)
Compliance: 98.7% (12 agents pending update)

Top deny reasons (last 24h):
  1. HIGH_VALUE_REFUND (342 denies)
  2. MASS_EMAIL_LIMIT (127 denies)
  3. DESTRUCTIVE_SHELL_COMMAND (89 denies)
```

### Fleet Budgets

Set aggregate budget across the entire org:

```yaml
# org-policy.yaml (Enterprise only)
faramesh-version: '1.0'
fleet: production

budgets:
  fleet:
    max_cost_usd_per_day: 5000.0
    on_exceed: defer
    notify: ["ops@example.com"]
    
  per_agent:
    max_cost_usd_per_day: 50.0
    on_exceed: cancel_remaining
```

## Compliance Exports

**Enterprise feature**: Generate compliance reports for SOC 2, HIPAA, GDPR, and EU AI Act.

### Export Audit Trail

```bash
faramesh compliance export \
  --format soc2 \
  --start 2026-01-01 \
  --end 2026-03-31 \
  --output audit-q1-2026.pdf
```

**Supported Formats:**
- `soc2` — SOC 2 Type II audit evidence
- `hipaa` — HIPAA audit log (healthcare)
- `gdpr` — GDPR data access log
- `eu-ai-act` — EU AI Act compliance report
- `iso27001` — ISO 27001 security controls

### Compliance Dashboard

View compliance posture in Faramesh Cloud:

```
https://cloud.faramesh.dev/compliance
```

**Includes:**
- Policy coverage heatmap
- Incidents prevented by category
- DEFER approval latency (SLA tracking)
- DPR chain integrity verification
- Credential rotation compliance
- Agent authentication audit

## Cloud Sync

**Pro feature**: Automatically replicate DPR chain to cloud for backup and cross-org analysis.

### Enable Cloud Sync

```yaml
# faramesh.yaml
cloud:
  sync_enabled: true
  sync_interval: 5m
  sync_endpoint: https://cloud.faramesh.dev/dpr/ingest
```

**Start daemon with cloud sync:**

```bash
faramesh auth login
faramesh serve --policy policy.yaml --cloud-sync
```

### Verify Sync Status

```bash
faramesh cloud sync status
```

**Output:**
```
Cloud Sync: ACTIVE
Last sync: 2m ago
Records synced: 1,247
Pending: 0
Errors: 0

Cloud endpoint: https://cloud.faramesh.dev/dpr/ingest
Backup retention: 90 days (Team plan)
```

<Note>
  DPR records are **encrypted in transit** (TLS 1.3) and **at rest** (AES-256). PII fields are redacted before sync.
</Note>

## Rolling Window Budgets

**Pro feature**: Time-based budget resets.

```yaml
faramesh-version: '1.0'
agent-id: customer-bot

budgets:
  - id: hourly-budget
    max_cost_usd: 10.0
    window: 1h
    on_exceed: deny
    
  - id: daily-budget
    max_cost_usd: 100.0
    window: 24h
    on_exceed: defer
    
  - id: monthly-budget
    max_cost_usd: 2000.0
    window: 30d
    on_exceed: defer
    notify: ["finance@example.com"]
```

**Budget resets automatically when the window expires.**

## Policy Pack Registry

**Pro feature**: Publish and consume community policy packs.

### Install a Policy Pack

```bash
faramesh hub install community/langchain-guardrails
# Installs to ~/.faramesh/packs/langchain-guardrails/
```

### Use Pack in Policy

```yaml
faramesh-version: '1.0'
agent-id: chatbot

imports:
  - pack: community/langchain-guardrails
    version: '1.2.0'

rules:
  - id: use-pack-rule
    match:
      tool: langchain/*
    effect: defer
    extends: langchain-guardrails.high-risk-tools
```

### Publish a Policy Pack (Team)

```bash
faramesh hub publish my-org/custom-guardrails --private
# Published to: https://hub.faramesh.dev/packs/my-org/custom-guardrails
```

## Cross-Org Swarm Policies

**Team feature**: Govern agents spanning multiple organizations.

```yaml
faramesh-version: '1.0'
fleet: cross-org-swarm

organizations:
  - org_id: acme-corp
    trust_domain: spiffe://acme.com
    
  - org_id: partner-inc
    trust_domain: spiffe://partner.com

rules:
  - id: cross-org-data-sharing
    match:
      when: 'principal.org != "acme-corp" && tool matches "db/read"'
    effect: deny
    reason: cross-org data access requires approval
    
  - id: defer-external-api-calls
    match:
      when: 'principal.org == "partner-inc" && tool matches "api/*"'
    effect: defer
    reason: external org API calls require Acme approval
```
